# AlphaPulse – Finance Market Risk and Volatility Dashboard

## 📌 About the Project

AlphaPulse is a finance market risk and volatility analysis project developed using **Python, Pandas, Excel, and Power BI**.

The project analyzes historical stock market data of **Reliance Industries, TCS, HDFC Bank, and Infosys** to evaluate stock performance, returns, volatility, portfolio risk, and Value at Risk (VaR).

## 🎯 Objectives

* Analyze historical stock market data
* Calculate daily and annual returns
* Measure stock volatility
* Analyze portfolio risk and performance
* Calculate covariance between stocks
* Perform Monte Carlo simulation
* Calculate Value at Risk (VaR) at 95% confidence level
* Develop an interactive Power BI dashboard

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/TanviPatange27/AlphaPulse-main.git
```

Go to the project folder:

```bash
cd AlphaPulse-main
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib yfinance jupyter
```

Run the Python files or Jupyter Notebook and open the Power BI dashboard.
